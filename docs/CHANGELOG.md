### v1.1.5 (2026-08-03)

**バグ修正**
* 同じブラウザで異なるプロジェクトフォルダのTaskFlowZeroを開いた際、設定画面のプラグイン情報に直前に開いていた別プロジェクトのプラグインフォルダの情報が混在して表示されてしまう不具合を修正。プラグインフォルダの記憶をプロジェクトフォルダごとに分離。同一タブ内でフォルダ履歴から別プロジェクトへ切り替えた場合も同様に混在しないよう対応。
* ガントチャートで今日の日付が土曜・日曜・登録した休みと重なる場合に、週末/休みの背景色が表示されなくなっていた不具合を修正。
* フィルター行（検索・マイルストーン等）とガントチャートの表示範囲行とで、左端のインデント位置がずれていた表示崩れを修正。
* タスク新規作成モーダルで、入力内容がある状態のまま誤って余白をクリックすると確認ダイアログが表示され煩わしかった問題を修正。何も入力していない場合は確認なしでそのまま閉じ、何か入力・編集している場合は余白クリックでは閉じない（ダイアログも表示しない）よう変更。「キャンセル」ボタン・Escキーでの操作は引き続き確認ダイアログを表示。

**機能追加**
* ガントチャートで、日付未設定のタスク行をドラッグすると開始日・期限を新規に設定できるように。
* ガントチャートの土曜・日曜の列に色付け（青系/赤系）を追加。日付ヘッダー・チャート本体の両方に反映。
* プロジェクト個別設定に「休み設定」タブを新設。日付を登録すると、ガントチャートに休みとして（日曜と同系色で）色付けされる。
* ガントチャートに、リスト・カンバンと共通のフィルター（検索・マイルストーン・担当者・ラベル・期限）を追加。表示範囲などのガント専用コントロールはフィルター行の下に配置。
* ガントチャートの表示範囲行にあった「タスク追加」ボタンを削除（フィルター行と重複するため）。「今日へ」ボタンをタスク追加ボタンと同系色に変更し、クリック時に一瞬色が変わるフィードバックを追加。
* コメントで見積/実績いずれかの工数のみを入力し本文が空の場合、自動で「工数入力」という本文を設定して投稿できるように変更。
* タスクパネルで「詳細情報」を折りたたんでいる間に表示されるラベルをクリックすると、そのラベルで一覧を絞り込めるように変更。
* タスクパネルにスクロールジャンプボタンを追加。コメント等でコンテンツが縦に長くなった場合に右下へ表示され、最下部への移動ボタンと最上部への移動ボタンが到達状況に応じて自動的に切り替わる。
* 設定画面のバージョン情報に、GitHub Sponsorsへの支援リンクを追加。

### v1.1.4 (2026-07-22)

**変更**
* リスト表示・カンバンカードでのラベル表示を、最大2件までの制限から全件表示に変更。表示エリアは折り返し（wrap）に対応済みのため、ラベル数が多い場合は複数行で表示されます。

**機能追加**
* Markdownのコードブロック言語選択肢に「Text」（言語未指定）を追加。
* タスクのチェックリスト追加欄（新規作成モーダル・タスクパネル編集の両方）で、改行を含むテキストをペーストした場合、1行につき1件のチェックリスト項目として追加されるように変更。改行を含まない通常のペーストは従来通りの挙動。
* `#P{プロジェクト番号}-{タスク番号}-C{コメント番号}`形式の参照リンクに対応。Markdown本文・コメント・Wiki内でこの形式のテキストを記述すると、該当タスクの該当コメントへ直接ジャンプするリンクになります（対象コメントが存在しない場合はリンク無効化＋取り消し線で表示）。

### v1.1.3 (2026-07-22)

**変更**
* プラグイン関連の設定（有効/無効・個別設定）を、プロジェクトフォルダ直下の `settings.json` から plugin フォルダ直下の新規ファイル `plugin-settings.json` に分離。プロジェクトフォルダ側に出力される `settings.json` はプラグインの設定値を持たなくなりました。
* 旧バージョンで `settings.json` にプラグイン設定が残っている場合、次回起動時（plugin フォルダへのアクセスが可能になったタイミング）に自動で `plugin-settings.json` へ移行し、`settings.json` 側からは削除されます。plugin フォルダ側に既に設定が存在する場合はそちらを優先し、上書きしません。
* `TaskFlow.registerPlugin()` / `TaskFlow.getPluginConfig()` など、プラグイン開発者向けAPIの呼び出し方法・戻り値に変更はありません。

### v1.1.2 (2026-07-10)

**バグ修正**
* タスクのコメントで見積時間を入力すると、タスク作成時に設定した見積時間が上書きされて消えてしまう不具合を修正。作成時の値を基準値として保持し、コメントでの入力はその基準値に対する加算として扱うように変更。
* 上記の修正に伴い、コメントの見積入力欄でマイナス値を入力できるように変更（見積を減らす調整が可能に）。実績入力欄は従来通りマイナス値を受け付けない。
* プラグインAPI（`TaskFlow.api.createTask` / `updateTask`）経由でタスクを作成・更新する場合も、同様の不具合が起きないように対応。

**機能追加**
* マイタスクのアクティビティタブで、指定した日付のアクティビティにタイムスタンプ（時刻）を表示するように変更。
* アクティビティの表示順を、時刻情報があるものは実際の時刻順、日付のみのものはその日の先頭にまとめる順序に変更。「その日、何時に何をしていたか」を振り返りやすくなりました。
