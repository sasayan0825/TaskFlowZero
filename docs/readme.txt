1. TaskFlowZero について
================================================================================

TaskFlowZero は、単一の HTML ファイルで動作するローカル型プロジェクト管理ツールです。
インターネット接続・サーバー・インストール作業は一切不要で、
HTML ファイルをブラウザで開くだけですぐに使用できます。

データはプロジェクトごとに JSON ファイルとして保存されるため、
フォルダをコピーするだけでバックアップが完了します。

主な機能:
  - 複数プロジェクトの管理
  - タスクのリスト / カンバン / ガント / バーンダウン表示
  - マイルストーン（マイルストーン → タスクの階層構造）
  - タスクのチェックリストと進捗率
  - タスクの優先度（高 / 低、リスト・カンバン・マイタスクに表示）
  - コメント＆アクティビティログ（変更履歴の自動記録）
  - コメントの編集（「編集済み」バッジ表示）
  - Markdown ツールバー（太字・斜体・コード・リスト・見出し、Ctrl+B/I ショートカット）
  - ファイル・画像の添付（tfz:// プロトコル、files/P{n}/ フォルダに保存）
  - 工数入力（予定工数 / 実績工数をコメント経由で記録・集計）
  - @メンション（メンバーをオートコンプリートで指定、バッジ表示）
  - マイタスク（担当タスク・メンション（既読 / 未読）・アクティビティ・いいねを横断表示）
  - URLでタスクを直接共有（コメントアンカーリンク対応）
  - プロジェクト単位のエクスポート / インポート（JSON / ZIP、添付ファイル同梱可）
  - 複数人利用対応（3-wayマージによる競合検知。自動保存中の競合は「保留」して後で解決）
  - スマホ対応（スマホモード。PC とは同期パッケージ（JSON）でデータを受け渡し。18章参照）
  - 添付ファイルの整理（使われていないファイルを「ゴミ箱」へ移動。19章参照）
  - Markdown 表示のサニタイズ・CSP などのセキュリティ対策（v1.2.3〜）
  - フォルダ履歴（最大10件、ワンクリックで再アクセス）
  - ライト / ダークテーマ切り替え
  - 自動保存
  - プラグインによる機能拡張（16章参照）

2. 動作環境
================================================================================

【PC（フル機能）】
  Google Chrome または Microsoft Edge（最新版推奨）

  理由: データファイルの読み書きに「File System Access API」を使用しており、
        共有フォルダなどを直接開いて保存するには、この API が必要です。

【スマホ・タブレット（スマホモード）】
  iPhone / iPad の Safari、Android の Chrome など、フォルダを選べない
  ブラウザで開くと、自動的に「スマホモード」で起動します。
  スマホモードはデータをブラウザ内（IndexedDB）に保存し、PC とは
  「同期パッケージ」（JSON ファイル）でやり取りします。
  閲覧と軽い更新（ステータス変更・コメント追加など）に向いています（18章参照）。

【フォルダを選べない PC のブラウザ】
  Firefox や、Mac の Safari など、File System Access API が無いブラウザで
  開いた場合も、PC であっても自動的にスマホモードで起動します。
  PC 版の全機能（共有フォルダでの複数人利用・プラグインなど）を使うには、
  Chrome または Edge で開いてください。

3. フォルダ構成
================================================================================

TaskFlowZero はデータを「フォルダ」単位で管理します。
プロジェクトごとに個別の JSON ファイルが生成されます。

  📁 （データフォルダ / 共有フォルダ）
  ├── project_P1.json          ← プロジェクトP1のデータ（自動生成）
  ├── project_P2.json          ← プロジェクトP2のデータ（自動生成）
  ├── 📁 files/                ← 添付ファイル（ファイル添付時に自動生成）
  │   ├── P1/                  ← プロジェクトP1の添付ファイル
  │   ├── P2/                  ← プロジェクトP2の添付ファイル
  │   └── _trash/              ← 添付ファイル整理で「ゴミ箱」へ移したファイル（19章）
  ├── taskflow_data.json       ← 旧形式ファイル（あれば自動移行）

  📁 （taskflowzero.html と同じフォルダ）
  ├── taskflowzero.html        ← 本体（これをブラウザで開く）
  ├── marked.min.js            ← オフライン対応する場合のみ（Markdownレンダリング）
  ├── chart.min.js             ← オフライン対応する場合のみ（バーンダウンチャート）
  └── 📁 plugin/               ← プラグインフォルダ（任意）
      ├── plugin_manifest.js   ← プラグイン一覧（自動生成）
      ├── plugin_loader.js     ← 読み込みロジック（自動生成）
      ├── plugin_lang.js       ← 言語切り替えプラグイン
      ├── plugin_search.js     ← 全体検索プラグイン
      ├── plugin_overdue_badge.js ← 期限切れバッジプラグイン
      └── plugin_csv_export.js ← CSVエクスポートプラグイン

【データフォルダと本体フォルダは別でも構いません】
  taskflowzero.html は任意の場所に置き、起動時にデータフォルダ（共有フォルダ等）
  を選択する形式です。

【旧形式（taskflow_data.json 単一ファイル）からの移行】
  旧形式のデータフォルダを開くと自動的に検出されます。
  次回保存時にプロジェクトごとの分割形式へ自動移行されます。

【オフライン（イントラネット）環境での利用】
  本体は、Markdown 表示用の marked と、バーンダウンチャート用の Chart.js を
  CDN（cdn.jsdelivr.net）から読み込みます。バージョンは固定で、SRI
  （ハッシュによる改ざん検知）付きです（v1.2.3〜）。
  インターネットに接続できない環境では、以下の2ファイルを
  taskflowzero.html と同じフォルダに置いてください。
  （データフォルダではありません。本体と同じフォルダです）

    marked.min.js  → https://cdn.jsdelivr.net/npm/marked@18.1.1/lib/marked.umd.js
    chart.min.js   → https://cdn.jsdelivr.net/npm/chart.js@4.5.1/dist/chart.umd.min.js
                     （ファイル名を chart.min.js に変更して保存）

  先に CDN からの読み込みを試み、失敗した場合（未接続・ハッシュ不一致を含む）に、
  上記のローカルファイルへ切り替えます。両方失敗した場合、Markdown プレビューと
  バーンダウンチャートが動作しません。

  以下の2つはオフライン環境でも機能に支障はありません:
    highlight.js   CDN取得失敗時（ハッシュ不一致を含む）は内蔵の自作ハイライターで
                   自動フォールバックします。コードブロックのシンタックス
                   ハイライトが簡易表示になりますが、表示自体は維持されます。
    Google Fonts   取得失敗時はOSのシステムフォントで表示されます。

  ※ v1.2.3 以降は CSP（Content-Security-Policy）により、本体から外部への通信は
    cdn.jsdelivr.net だけに制限されています。

4. はじめかた
================================================================================

【初回起動】

  1. taskflowzero.html をダブルクリック（または Chrome/Edge にドラッグ）して開く

  2. 起動画面が表示されます。以下いずれかを選択してください:

     ● 新規作成
       「✨ 新規作成」ボタンをクリック
       データを保存するフォルダ（共有フォルダ等）を選択する
       プロジェクト管理画面が開きます

     ● 既存フォルダを開く
       「📂 別のフォルダを開く」ボタンをクリック
       既存のデータフォルダ（project_P*.json が入ったフォルダ）を選択する

【2回目以降】

  フォルダ履歴から前回使用したフォルダを選択できます（最大10件）。
  「↩ 開く」ボタンをクリックするだけで再開できます。
  ※ ブラウザにアクセス許可を求められた場合は「許可」を選択してください。

5. データファイルについて
================================================================================

TaskFlowZero のデータはプロジェクトごとに個別の JSON ファイルとして保存されます。
ファイル名は自動で割り当てられたプロジェクト番号に基づきます（例: project_P1.json）。

【保存タイミング】
  - タスクやプロジェクトを変更すると約1.2秒後に自動保存されます
  - Ctrl + S（Mac: ⌘ + S）で手動保存も可能です
    ※ 自動保存・手動保存のどちらでも、他のユーザーの変更とのマージ・競合チェックが
      行われます（6章参照）

【バックアップ】
  データフォルダごとコピーするだけでバックアップが完了します。
  ※ 添付ファイル整理で「ゴミ箱」へ移したファイル（files/_trash/）も同じフォルダ内にあります。
  添付ファイルも files/ フォルダに含まれるため、合わせてコピーしてください。
  例: taskflow_backup_20260314/ というフォルダ名でコピーして保管

【プロジェクト番号の自動採番】
  プロジェクトには自動で番号が割り当てられます（P1, P2, P3...）。
  旧形式の JSON を開いた際に番号が未設定の場合は自動採番されます。

6. 複数人での利用（保存競合の検知とマージ）
================================================================================

TaskFlowZero は同じデータフォルダを複数人で共有して利用できます。
保存のたびに、他の人の変更を「3-wayマージ」と呼ぶ仕組みで取り込み、
同じ項目を別々に変更した場合は競合として検知します。

【基本的な使い方】
  1. 共有フォルダ（社内ネットワーク, OneDrive, Dropbox 等）を
     データフォルダとして指定する
  2. 各自の PC から同じフォルダを開く
  3. 編集すると自動保存され、他者の変更が自動で取り込まれる
     （Ctrl + S で手動保存することも可能）

【保存時の動作】

  ● 他の人が別のタスク・別のプロジェクトを変更していた場合
    → 競合なし。自動マージして保存されます。
       トーストに「他の変更を自動マージ」と表示されます。

  ● 同じタスクの同じ項目を別々に変更していた場合
    → 競合あり。保存の種類によって動作が異なります。

      ・手動保存（Ctrl+S）・タブ切替・パネルを開いたときなど
        競合ダイアログが表示されます。左列（自分の変更）と右列（相手の変更）を
        比較し、どちらを残すか行ごとにボタンで選択できます。
        「すべて自分を残す」「すべて相手を残す」の一括選択も可能です。
        長い文章（コメント・詳細・Wiki など）は全文を表示し、長い場合は各欄の
        中でスクロールして確認できます。自分の変更と相手の変更で異なる箇所は
        色が変わって表示されます（自分は青、相手は紫）。
        ダイアログで「キャンセル」を押すと、競合した項目は「保留」になります。

      ・自動保存中（編集後 約1.2秒で実行）
        確認なしで相手の値に置き換えることはしません。競合した項目は
        「保留」として自分の値を残したまま、競合していない変更だけを保存します。
        保留がある間は画面下に「他の人の変更と重なった項目が N 件あります」という
        バナーが表示されます。「解決する」ボタンまたは Ctrl+S で解決ダイアログを
        開き、「自分の変更を残す／相手の変更を残す」を選んでください。
        保留後にさらに別の値へ変更した項目は、競合から外れます。

  ● タスクの「詳細」欄・Wiki の本文
    → 行単位で自動マージします。別々の行を編集していた場合は競合しません。
       同じ行付近を両者が編集して重なった場合は、競合として扱われます
       （自動保存中は自分の内容を残して保留）。Wiki の編集中に他の人が同じページを
       保存しても、編集内容と他の人の変更が行単位でマージされ、入力中のカーソル位置は
       保たれます。

  ● コメント・チェックリスト
    → コメントの追加・削除、「いいね」・ブックマーク・メンション既読、
       チェックリスト項目の追加・チェックの切り替えは、両方を取り込んでマージされます
       （競合扱いにはなりません）。「いいね」・ブックマーク・既読は、コメント本文の
       編集とは別にマージされるため、本文の編集が消えることはありません。
       ただし、同じコメントの本文、または同じチェックリスト項目の文言を
       両者が別々に編集した場合は、タスクの項目と同様に競合として扱われます。

  ● アクティビティログ・週次メモ
    → アクティビティログは両方を取り込んでマージされます。
       週次メモは同じ週を両者が編集した場合、更新日の新しい方が採用されます。

  ● プラグインが追加した項目・Wiki ページの並び順
    → 他の項目と同様に3-wayマージされます。

【OneDrive / Dropbox の競合コピーについて】
  OneDrive や Dropbox は同時編集時に「競合コピー」ファイルを自動生成することがあります。
  （例: project_P1 (田中 の競合コピー 2026-03-14).json）
  TaskFlowZero はフォルダを開いた際にこれらを自動検出し、3-wayマージを試みます。
  競合のない変更は自動マージ、同じフィールドへの競合は手動解決ダイアログを表示します。
  解決後、競合コピーファイルは自動的に削除されます。

【他の人の変更を取り込むタイミング】
  手動保存（Ctrl+S）のほか、以下の操作でも自動的に取り込まれます:

    - ビュータブを切り替えたとき（リスト↔ガント↔カンバン 等）
    - タスク詳細パネルを開いたとき
    - ヘッダーの「🔄 更新」ボタンをクリックしたとき

  ※ タスクパネルに未保存の変更がある状態でタブを切り替えた場合は
    上書き防止のためマージをスキップします。

【注意事項】
  - 自動保存も、書き込む前にファイルを読み直して他の人の変更とマージします。
    ほかの人の変更をすぐに確認したいときは、ヘッダーの「🔄 更新」か Ctrl+S を
    使ってください。
  - ファイルの読み込みに失敗した場合（JSON の破損・同期の途中・ロック中など）は、
    他の人の変更を消さないよう、保存を保留して数秒後に自動で再試行します。
    6回失敗すると警告が表示されます。フォルダの状態を確認してから、
    Ctrl+S で保存し直してください。
  - 保留中の競合や未保存の変更が残っている状態でページを閉じようとすると、
    確認ダイアログが表示されます。
  - 書き込み直前にファイルが更新されていないかも再確認し、更新されていれば
    読み直してマージし直します。ただし、全く同時（ミリ秒単位）の書き込みは
    防ぎきれない場合があります。

8. プロジェクト管理
================================================================================

【作成】
  プロジェクト一覧画面の「＋ 新規プロジェクト」ボタンをクリック
  名前・説明・期間・メンバー・カラーを設定する

【プロジェクト番号】
  各プロジェクトには自動で番号が割り当てられます（P1, P2, P3...）。
  この番号はタスクの直接URLに使用されます（14章参照）。
  既存の JSON を開いた際に番号が未設定の場合は自動採番されます。

【検索・絞り込み】
  プロジェクト一覧画面では、プロジェクト名やメンバー名で検索できます。

【完了（アーカイブ）】
  プロジェクトが完了したら「📦 完了」ボタンを押します。
  アーカイブされたプロジェクトはグレーアウトされ、下部に分類されます。
  「♻️ 未完了に戻す」でいつでも復元できます。

【編集・削除】
  プロジェクトカードの「✏️」「🗑」ボタンで操作できます。
  ※ 削除は取り消せません。

【エクスポート / インポート】（v1.1.7〜）
  プロジェクトを丸ごと別のTaskFlowZero環境（別のデータフォルダ）へ
  持ち出したいときに使います。

  ＜エクスポート＞
    1. プロジェクト画面の「⚙️ 設定」→「保存」タブを開く
    2. 添付ファイル（画像・ファイル）も含めたい場合は
       「添付ファイルを含める」にチェックを入れる
       - チェックなし: project.json 相当の内容を .json でダウンロード
       - チェックあり: project.json ＋ files/P{n}/ 配下の添付ファイル一式を
         .zip でダウンロード
    3. 「📤 エクスポート」ボタンでダウンロード

  ＜インポート＞
    1. インポート先の環境で「プロジェクト一覧」画面右上の
       「📥 インポート」ボタンをクリック
    2. エクスポートした .json または .zip ファイルを選択

  ＜インポート時の自動処理＞
    - プロジェクトID・プロジェクト番号は、インポート先の環境に合わせて
      自動的に新しく採番し直されます（元の番号のままにはなりません）。
    - タスク説明・コメント・Wikiページ本文に含まれる参照リンク
      （#P{番号}-{タスク番号} 形式、14章参照）、添付ファイルへのリンク
      （tfz://P{番号}/... 形式）、Wikiページ・見出しへのリンク
      （wiki://P{番号}-{ページID}#{見出しID} 形式、11-5章参照）も、
      新しいプロジェクト番号へ自動的に書き換えられます。
      これにより、インポート先にたまたま同じ番号の別プロジェクトが
      存在していた場合でも、誤って別プロジェクトのタスクにリンクして
      しまうことを防ぎます。
    - #10 や #C1 のような省略記法（12章参照）はプロジェクト番号を
      含まず、参照する時点で開いているプロジェクト・タスクに応じて
      その都度解決されるため、上記の書き換え対象には含まれません
      （番号が変わっても書き換え不要でそのまま正しく機能します）。
    - .json 形式でインポートした場合、添付ファイルの実体は含まれていない
      ため復元されません。本文に添付ファイルへの参照がある場合は
      インポート後に警告メッセージが表示されます。
      添付ファイルも一緒に移行したい場合は、エクスポート時に必ず
      「添付ファイルを含める」（.zip 形式）を選択してください。
    - 同名のプロジェクトが既に存在していても重複チェックは行われず、
      そのままインポートされます。

================================================================================
9. タスク管理
================================================================================

【作成】
  画面上部「＋ タスク追加」ボタン、またはカンバンビューの「＋ タスクを追加」から

  設定できる項目（追加モーダルの並び順）:
    タイトル（必須）
    作成者              /  優先度（高 / 低 / 未設定）
    ステータス          /  担当者
    開始日              /  期限
    ストーリーポイント  /  マイルストーン
    ラベル（色付きタグ、自由に追加可）
    詳細（Markdown、添付ファイル対応）

【優先度】（v1.1.7〜）
  タスクに「高」「低」の優先度を設定できます（未設定も可）。
  タスク詳細パネルのタイトル先頭、リストビューのタイトル先頭にも
  同じバッジが表示され、優先度を変更するとリアルタイムに切り替わります。

    高 → 赤い「↑」バッジ、カンバンではカード背景が薄い赤系グラデーション
    低 → 灰色の「↓」バッジ、カンバンではカード背景が薄い灰系グラデーション

  「マイタスク」画面の「担当タスク」一覧にも優先度列が表示されます。

【ステータスと進捗】
  ステータスを「完了」に変更すると完了日が自動セットされ、完了にした人の名前
  （右上のアカウントに設定した名前）も記録されます（v1.1.29〜）。
  マイタスクのアクティビティでは、この完了にした人の実績として集計されます。
  カンバンのドラッグ&ドロップでステータスを変えた場合も、変更した人の名前付きで
  アクティビティに記録されます。
  チェックリストの完了率はステータス「完了」にした時点で100%になります。

【@メンション】
  タスク詳細、コメント、Wiki のテキスト入力中に「@」を入力すると
  プロジェクトメンバーの候補がポップアップ表示されます。
  ↑↓ で選択して Tab または Enter で確定します。
  メンションされたメンバーには「マイタスク」画面で通知が表示されます
  （既読・未読の管理ができます。13章参照）。

【工数入力】
  タスク詳細パネルのコメント欄下部「＋ 工数を追加」ボタンから
  予定工数（h）と実績工数（h）をコメントと一緒に記録できます。
  記録した工数はコメント欄に履歴として表示されます。

【ファイル・画像の添付】
  詳細テキストエリアやコメント欄のツールバーにある 📎 ボタンからファイルを選択します。
  添付されたファイルは files/P{n}/ フォルダに保存され、
  tfz:// プロトコルで管理されます。
  画像はプレビューにインライン表示、その他はダウンロードリンクとして表示されます。

10. マイルストーン
================================================================================

マイルストーンはタスクをグループ化する単位です。
プロジェクト → マイルストーン → タスクの3階層で管理します。

【作成・編集】
  プロジェクト画面上部の「🏁 マイルストーン」ボタンをクリック

  設定できる項目:
    名前 / 説明 / 開始日 / 終了日 / カラー

【並び替え】
  マイルストーン一覧でドラッグ&ドロップによる並び替えが可能です。
  並び順はリストビューとガントチャートに反映されます。

================================================================================
11. ビュー一覧
================================================================================

プロジェクト画面上部のタブでビューを切り替えます。
タブを切り替えるたびに他のユーザーの変更が自動で取り込まれます。

────────────────────────────────────────
11-1. リストビュー
────────────────────────────────────────

タスクをマイルストーン別の表形式で表示します。

【タブ】
  未完了 / 完了 / 全て の3つのタブで表示を切り替えられます。
  タブ行はスクロールしても画面上部に固定されます。

【フィルター】
  - テキスト検索（タイトル部分一致）
  - マイルストーン絞り込み
  - 担当者絞り込み
  - ラベル絞り込み
  - 期限絞り込み（開始前 / 期間内 / 期限切れ / 期限なし）
  - フィルターバー右端の「×」ボタンで、すべての絞り込みを初期状態に戻せます
  - タスクを開いて保存しても、マイルストーンなどの絞り込みは維持されます

【列の表示内容】
  # / タイトル / ステータス / 担当者 / 期限 / 進捗（チェックリスト） / 開始日 / SP

  「進捗」列ではチェックリストの達成率をミニプログレスバーで確認できます。

【タスクの並び替え】
  行左端の ⠿ ハンドルをドラッグすると、同一マイルストーン内でタスクを並び替えられます。
  並び順はガントチャートにも反映されます。

【グループの折りたたみ】
  マイルストーン行をクリックすると、そのグループのタスクを折りたたみます。

【マイルストーン行の色分け（ライトモード）】
  マイルストーン行は青色背景で表示され、タスク行と明確に区別できます。

【マイルストーンのツールチップ】
  説明が設定されているマイルストーン行には 💬 アイコンが表示されます。
  行にマウスを乗せると 0.2秒後 に説明内容がツールチップで表示されます。

────────────────────────────────────────
11-2. カンバンボード
────────────────────────────────────────

タスクをステータス別（To Do / 進行中 / レビュー / 完了）のカードで表示します。

【操作】
  - カードをドラッグ&ドロップでステータス変更
  - カードをクリックで詳細パネルを開く

【スクロール】
  タスクが多い列はカード一覧エリアのみスクロールされます。
  「＋ タスクを追加」ボタンは各列の下部に常時表示されます。

────────────────────────────────────────
11-3. バーンダウンチャート
────────────────────────────────────────

スプリント期間中のストーリーポイント消化状況をグラフで確認できます。

  - 灰色の線: 理想消化ライン
  - 青色の線: 実際の残ポイント推移

タスクに「ストーリーポイント」が設定されていると、
より正確な進捗をグラフで確認できます。

────────────────────────────────────────
11-4. ガントチャート
────────────────────────────────────────

マイルストーンとタスクを時系列バーで可視化します。

【表示範囲の切り替え】
  1ヶ月 / 3ヶ月 / 6ヶ月 / 1年から選択できます。

【タスク表示・タスク横の表示】
  表示範囲欄の「タスク表示」で「すべて」「未完了のみ」「なし」を選べます
  （初期値は「すべて」）。「タスク横：担当者／SP」で、タスク名の横に出す
  内容を切り替えられます（初期値は「担当者」。選択はこの端末に記憶されます）。
  タスク名にマウスを乗せると、タスク名全文・担当者・SP・期間を表示します。

【起点の設定】
  「今日起点」または「プロジェクト開始日起点」を選択できます。

【バーのドラッグ操作】
  左端をドラッグ  → 開始日を変更
  右端をドラッグ  → 終了日（期限）を変更
  中央をドラッグ  → 期間全体をずらす
  ドラッグ中は日付のツールチップが表示されます。

【進捗率の計算（チェックリスト連動）】
  ステータス「完了」           → 100%
  チェックリストあり（未完了） → チェック数 ÷ 総数（最大 99%）
  チェックリストなし（未完了） → 0%
  マイルストーンバーの進捗はタスクのSP加重平均で算出されます。

【イナズマ線】
  各マイルストーンの進捗を繋いだ折れ線を表示します。
  100%完了かつ終了日が過去、または 0%かつ開始日が未来の場合は
  ドット位置を「今日」に補正します。

────────────────────────────────────────
11-5. Wiki
────────────────────────────────────────

プロジェクトごとの自由記述スペースです。Markdown 形式で記述できます。
右パネルに自動生成された目次（TOC）が表示されます。
本文をスクロールすると、現在表示中の見出しが目次でハイライトされます（スクロールスパイ）。
目次の項目をクリックすると、対応する見出しへスムーズにスクロールします。
編集モードでも、目次をクリックすると編集欄内の該当見出しへ移動し、カーソルも
見出しの行頭に移ります（v1.1.25〜）。目次は入力に合わせて更新されます。

【ツールバー】
  太字 / 斜体 / コード / リスト / H などのボタンで書式を挿入できます。
  コードブロックの言語候補には JS / Python / Bash / SQL / YAML などに加え、
  「Properties」（.properties / application.properties 形式）を選択できます。
  📎 ボタンからファイル・画像を添付できます（添付したファイルは files/ フォルダに保存）。

【見出しへの直接リンク】（v1.1.12〜）
  Wikiの見出しにカーソルを合わせると🔗アイコンが表示されます。
  クリックすると「ページ名 > 見出し名」形式のMarkdownリンクがクリップボードに
  コピーされます。ページ全体（先頭 or 現在表示中のページ）へのリンクが欲しい
  場合は、ツールバーの「🔗 リンク」ボタンを使います。

  コピーしたリンクをタスクのコメント・詳細欄・他のWikiページ本文に貼り付けると、
  自動的にクリック可能なリンク（📖アイコン付き）に変換されます。
  クリックすると、対象プロジェクトを開き、Wikiビューへ切り替えて該当ページ・
  見出しまで自動的にスクロールします。

  内部形式: wiki://P{プロジェクト番号}-{ページID}#{見出しID}
  （プロジェクトをまたぐリンクも可能です）

  ※ 見出しIDは見出しの文言から自動生成されるため、見出しの文言を変更すると
    既存のリンクは見出しを特定できなくなります（リンクは打ち消し線表示になり、
    クリックしても「見出しが見つかりません」という通知が表示されます）。
    ページ自体へのリンクはページの内部IDに基づくため、ページ名を変更しても
    引き続き有効です。

【自動保存】
  「プレビュー」タブに切り替えると自動的にWikiが保存されます。

================================================================================
12. タスク詳細パネル
================================================================================

タスクをクリックすると画面右側に詳細パネルが開きます。
パネルを開いた際、他のユーザーの最新変更が自動で取り込まれます。

【パネル幅の変更】
  パネル左端をドラッグすると幅を変更できます（最小幅: 640px）。
  設定した幅はブラウザに記憶されます。

【チェックリスト】
  - Enter で項目追加
  - テキスト部分をクリックしてインライン編集（Enter/blur で保存、Esc でキャンセル）
  - ⠿ ハンドルをドラッグして並び替え
  - 進捗率 = チェック数 ÷ 総数（最大 99%、完了ステータスで 100%）

【詳細（Markdown）】
  「プレビュー」タブがデフォルトで表示されます。
  「編集」タブで入力、「プレビュー」タブで確認。
  ツールバーの各ボタン（太字・斜体・コード・リスト・見出し）や 📎 ファイル添付が使えます。
  プレビューエリアの高さはドラッグで変更可能で、ブラウザに記憶されます。

  【表ボタン（⊞）での変換】（v1.1.24〜）
    Excel などからコピーしたタブ区切りのテキストを選択して表ボタンを押すと、
    「1行目をヘッダーにする」「ヘッダーは空欄にする」のどちらかを選んで
    Markdown の表に変換できます。Ctrl+Z で元に戻せます。

  【Tab キーと Esc キー】（v1.1.24〜）
    Markdown の入力欄では、Tab キーでタブ文字を入力します。複数行を選択して
    Tab で字下げ、Shift+Tab で戻せます。Esc を押すと「Tab移動モード」になり、
    Tab で次の入力項目へ移動できます（入力欄の枠が黄色の点線になります）。
    文字入力を再開すると、Tab で入力するモードに戻ります。

  【表示できる HTML】（v1.2.3〜）
    Markdown に直接書いた HTML は、安全のためサニタイズして表示されます。
    <br> <u> <mark> <details> <table> などの一般的なタグは使えますが、
    <script> <iframe> <form> <svg>、on… 属性、id 属性などは取り除かれます。
    外部の画像は https のものだけ表示されます。

【工数 (h)】
  タスクの予定総工数を直接入力できます。
  コメント経由で入力した実績工数の累計も合わせて確認できます。

【コメント＆アクティビティ フィルター】
  すべて / 💬 コメントのみ / 🔄 アクティビティのみ の3種類。
  設定はブラウザに保存されます。

  コメントは Markdown 形式で記述でき、プレビュー表示にも対応しています。
  ツールバーから太字・斜体・コード・リスト・見出しの挿入、📎 ファイル添付が使えます。
  テキストエリアは入力に応じて自動的に高さが伸縮します。

  投稿済みコメントは ✏️ ボタンで編集でき、編集後は「編集済み」バッジが表示されます。

  「＋ 工数を追加」ボタンからコメントに予定工数・実績工数を付加して記録できます。

  @メンション: テキスト入力中に「@」を入力するとメンバー候補が表示されます。

  タスク・コメント参照リンク: コメントや詳細欄に以下のように書くと自動でリンク化されます。
    #P1-10       → プロジェクトP1のタスク10（14章参照。フォルダをまたいでも一意）
    #P1-10-C1    → 上記タスクのコメント1
    #10          → 今開いているプロジェクト内のタスク10（省略記法）
    #C1          → 今開いているタスクのコメント1（省略記法。
                   Wikiページ本文など「今開いているタスク」が定まらない場所では解決されません）
  省略記法はテキストが書かれた時点の文脈（今開いているプロジェクト／タスク）に依存するため、
  別のプロジェクトへコピー＆ペーストすると意図しないタスクを指してしまう場合があります。
  プロジェクトをまたいで確実に参照したい場合は #P1-10 のようなフル表記を使ってください。
  コメント番号（C1等）は投稿順に固定で採番され、途中のコメントを削除しても
  他のコメントの番号は変わりません（削除された番号は欠番のまま残ります）。

  自動記録される操作:
    ステータス / 担当者 / 期限 / 優先度の変更、詳細内容の更新、チェックリストの操作
    （変更した人の名前付きで記録されます。名前が未設定の場合は名前なしです）

【詳細情報の折りたたみ】
  「詳細情報」を折りたたんでいるときは、ラベルの左にマイルストーン名が表示されます
  （v1.1.29〜）。クリックすると、そのマイルストーンで一覧を絞り込みます。

【被リンク】
  タスクパネルには、このタスクを参照している他のタスクが、ステータスのバッジ付きで
  表示されます（#P2-5 のフル表記のほか、#5 の省略記法も対象です）。

13. マイタスク
================================================================================

サイドバーの「👤 マイタスク」をクリックすると、全プロジェクトを横断して
自分に関係する情報をまとめて確認できます。

【タブ構成】

  💬 メンション
    自分が @メンションされたコメントの一覧です。
    プロジェクト名・タスク名・メンション本文が表示されます。
    カードをクリックするとタスク詳細パネルが開き、コメントへスクロールします。

    既読・未読（v1.2.1〜）:
      未読のメンションはカードの左に青い線と「●」が付き、既読は薄く表示されます。
      カードをクリックしてタスクを開くと自動で既読になります。
      「✓ 既読にする」「↩ 未読に戻す」ボタンで手動でも切り替えられます。
      絞り込みで「未読のみ」を選べ、件数は「N件（未読 M）」と表示されます。
      「すべて既読にする」で、表示中の条件の未読をまとめて既読にできます。
      既読の状態は自分の分だけが保存され、他の人には影響しません。
      データフォルダに保存されるため、別の PC でも同期されます。
      ※ 2026-11-02 より前に投稿されたメンションは、最初から既読です。

  📋 担当タスク
    自分が担当者として割り当てられているタスクの一覧です。
    プロジェクト・ステータスでフィルターできます。
    期限 / ステータス / プロジェクト名でソートできます。

  📊 アクティビティ
    自分の活動を、日ごとの色の濃さ（ヒートマップ）で表示します。
    日付を選ぶと、その日のタイムライン（時刻順）と「プロジェクト別実績」が
    表示されます。
      - 見出しの横の「◀ 前日」「翌日 ▶」で、隣の日へ移動できます。
      - 5分以内に続けて発生した活動は「N件」にまとめられ、クリックで展開できます。
      - 「プロジェクト別実績」は、プロジェクト → マイルストーン → タスクの
        階層で表示します。行をクリックで展開・折りたたみ、右上の
        「すべて展開」「すべて折りたたむ」で一括操作できます。
      - 投稿したコメントをクリックすると、そのコメントまでスクロールして開きます。
      - タスクの完了は、完了にした人の実績として集計されます。

  ❤️ いいね
    「受け取った」「いいねした」「ブックマーク」を切り替えて確認できます。
    プロジェクトで絞り込めます。「受け取った」は年ごとに切り替えられます。

  ※ いずれのタブでタスクをクリックしても、プロジェクト詳細画面へは遷移せず
    マイタスク画面に留まったままタスク詳細パネルが開きます。

【バッジ】
  サイドバーの「マイタスク」項目に、未読のメンション数と担当タスク数が
  バッジとして表示されます。

【自分の名前の設定】
  マイタスクを利用するには、画面右上のアカウントボタンをクリックし、
  自分の名前を選択しておく必要があります（v1.1.25〜。以前の「自分」プルダウンは
  廃止されました）。未設定の間はサイドバーに赤い「未設定」バッジが表示され、
  アカウントボタンが「名前を選択」と表示されて点滅します。
  アカウントボタンのメニューには、「アバター画像を設定」「名前を変更」
  「未設定にする」もあります。
  名前を設定しておくと、コメント投稿時の投稿者名にも自動的に反映され、
  投稿者名が空のままコメントを投稿しようとした場合は、「名無し」のまま
  投稿するかどうかを確認するダイアログが表示されます。
  名前はフォルダごとにこのブラウザに保存されます（認証機能はありません）。

14. URLでタスクを直接開く
================================================================================

【URL形式】
  file:///C:/Users/.../taskflowzero.html#P1-42
  file:///C:/Users/.../taskflowzero.html#FolderName-P1-42
  file:///C:/Users/.../taskflowzero.html#FolderName-P1-42-C3

  P1    → プロジェクト番号
  42    → タスク番号
  C3    → コメント番号（省略可。指定するとそのコメントにスクロール）

  ※ ブラウザのURL欄・お気に入り等から開く場合は、まだどのプロジェクトも
    開かれていない状態からのアクセスになるため、12章で説明した #10 や #C1
    のような省略記法は使えません。必ずこのフル表記（#P1-42 等）を使ってください。
  FolderName → データフォルダ名（省略可。URLコピーボタンで自動付加）

タスク詳細パネルの「🔗 URLコピー」ボタンでクリップボードにコピーできます。
コメント行のアンカーリンクからは、そのコメントへ直接ジャンプする URL をコピーできます。

履歴にそのフォルダがあり、アクセス許可が残っている場合は、フォルダ選択画面を
表示せずに自動でフォルダを開いて、該当のタスクへ移動します（v1.1.27〜）。
履歴にない場合やアクセス許可が切れている場合は、これまでどおりフォルダ選択画面が
表示されます。

URLはローカルファイルパスを含むため、別PCへそのまま送っても使用できません。
同じ共有フォルダに taskflowzero.html を置き、同じパスでアクセスしている場合は動作します。

16. プラグイン
================================================================================

TaskFlowZero はプラグインで機能を拡張できます。
プラグインの管理はヘッダーの「🔌」ボタンから開くプラグイン管理モーダルで行います。

【プラグインのインストール】
  1. ヘッダーの「🔌」ボタンをクリック
  2. .js ファイルをドラッグ&ドロップ、またはファイル選択でインストール
  3. 「保存」ボタンで plugin_manifest.js に反映し、ページをリロードすると有効になります

【plugin_manifest.js / plugin_loader.js について】
  プラグインフォルダ内の plugin_manifest.js が、読み込むプラグイン名の一覧
  （マニフェスト）です。plugin_loader.js は実際の読み込み処理ロジックで、
  プラグイン名は含みません。モーダルから「保存」すると両方とも自動的に
  書き換えられます。手動で編集することも可能です。
  （旧バージョンで使用していた plugins.js は、次回保存時にこの2ファイルへ
  自動的に移行されます）

【プラグインの並び替え・削除】
  モーダル内のリストで ⠿ ハンドルをドラッグして読み込み順を変更できます。
  🗑 ボタンで一覧から削除できます（ファイル自体は残ります）。

現在提供されているプラグイン（plugin/ フォルダ）:

  plugin_lang.js           言語切り替え（日本語 ⇔ 英語）
  plugin_search.js         全体検索（全プロジェクトのタスク・コメント・Wikiを横断検索。
                           プロジェクト・マイルストーンで絞り込み可。Ctrl+Shift+F）
  plugin_overdue_badge.js  期限切れバッジ（期限を過ぎた未完了タスクの件数を
                           サイドバーに表示。クリックで一覧）
  plugin_csv_export.js     CSVエクスポート（タスク一覧をCSVで出力）

  プラグインを自作する場合は docs/PLUGIN_DEVELOPER_GUIDE.txt を参照してください。

【スマホモードでは読み込まれません】
  スマホモード（18章）では、プラグインは読み込まれません。

17. ショートカット・操作ヒント
================================================================================

  Ctrl + S（Mac: ⌘ + S）  手動保存（競合チェックも実行。保留中の競合があれば解決ダイアログ）
  Ctrl + Shift + F         全体検索（全体検索プラグイン使用時）
  Tab / Shift + Tab        Markdown入力欄でタブ入力・字下げ（Escで次の項目へ移動できるモードに切替）
  Ctrl + B                 太字（コメント・詳細・Wiki のテキストエリアにフォーカス中）
  Ctrl + I                 斜体（同上）
  Escape                   開いているパネル・モーダルを閉じる

  【ヘッダーボタン】
  - 🔄 更新: 他のメンバーの変更を即時取得（Ctrl+S を押さずに確認したいとき）
  - 📂 フォルダ変更: 別のデータフォルダに切り替える
  - 🔌 プラグイン: プラグイン管理モーダルを開く
  - アカウント（右上）: 「自分」の名前を切り替える

  【その他のヒント】
  - タスクの「#番号」は自動採番されます（変更不可）
  - ラベルを入力欄に打ち込んで Enter を押すだけで追加できます
  - マイルストーン一覧でドラッグ&ドロップによる並び替えが可能です
  - リストビューの ⠿ ハンドルでタスクの表示順を変更できます（ガントにも反映）
  - ガントのバーをドラッグすると日付を直接変更できます
  - チェックリストの ⠿ ハンドルをドラッグすると並び替えられます
  - コメントフィルター / プレビュー高さの設定はブラウザに保存されます
  - @メンションで入力した @ の後にメンバー名を打つと候補が絞り込まれます
  - 起動画面のフォルダ履歴は最大10件保存され、一括削除も可能です

18. スマホで使う（スマホモード）
================================================================================

フォルダを選べないブラウザ（iPhone / iPad の Safari、Android の Chrome など）で
開くと、自動的に「スマホモード」で起動します（v1.2.0〜）。PC の Chrome / Edge で
URL の末尾に ?mobile=1 を付けて開くと、同じ画面を確認できます（?mobile=0 で
PC モードに固定）。

【データの保存場所】
  スマホモードでは、データはブラウザ内（IndexedDB）に保存されます。
  PC のデータフォルダとは別物で、自動では同期されません。
  ブラウザによっては保存が消えることがあるため、iPhone ではホーム画面に追加して
  使うことをお勧めします。

【PC とのデータの受け渡し（同期パッケージ）】
  Teams などでファイルを送り合う前提で、フォルダの共有は不要です。
  操作は「⚙️ 設定 → 📱 スマホ連携」にまとまっています。

  PC → スマホ
    PC で「スマホ用に書き出し」を押し、プロジェクトを選んで 1 つのファイルに
    まとめます。スマホで「パッケージを取り込む」から開きます。
    取り込むと、スマホ側のデータはその内容に置き換わります
    （パッケージに含まれないプロジェクトはスマホから消えるため、確認が出ます）。

  スマホ → PC
    スマホで「変更を書き出し」を押すと、取り込んだ時点からの自分の変更分だけが
    書き出されます（差分パッケージ）。PC で「スマホの変更を取り込み」から開くと、
    3-wayマージで反映されます。食い違う項目だけ、6章と同じ競合ダイアログで
    選べます。同じパッケージを2回取り込んでも、重複しません。

  スマホから PC へ反映されるのは、ステータスなどタスクの項目の変更、
  チェックリストの操作、コメントの追加、新規タスクです。
  タスクやプロジェクトの削除、プロジェクト・マイルストーン・Wiki の編集は
  PC から取り込んだプロジェクトでは反映されません（編集ボタンは出ません）。
  スマホで追加したタスクの番号は仮のもので、PC への取り込み時に振り直されます。

  書き出していない変更が3日以上たまっていると、起動時にお知らせします。
  PC へ送っていない変更の件数は、左メニューの「設定」横のバッジにも表示されます。

【PC をまだ使っていない場合】
  取り込み画面の「新規で始める」から、スマホだけで始められます。
  スマホで作ったプロジェクトは、プロジェクト情報・マイルストーン・Wiki も
  スマホで編集できます（削除はできません）。PC には、プロジェクト全体として
  取り込まれます。

【画面の違い】
  左メニューは「☰」で開きます。カンバンは1列ずつスワイプで見られ、
  タスク詳細は画面いっぱいに開きます。ガントとバーンダウンは、スマホを
  横向きにすると広く使え、右下の「⤢」で全画面にできます。
  プラグインは読み込まれません。

19. 設定画面（添付ファイルの整理など）
================================================================================

サイドバーの「⚙️ 設定」で開きます。「📋 バージョン」「📱 スマホ連携」
「📎 添付ファイル」「🔌 プラグイン」の4つがあります（スマホ連携はスマホモードの
連携操作用で、添付ファイルは PC 版のみです）。

【📎 添付ファイル（v1.2.2〜）】
  添付ファイルの肥大化を防ぐため、フォルダ内の files/ を調べて、使われている
  ファイルと使われていないファイルを一覧にします。「🔍 スキャン」を押したときだけ
  調べます（自動では実行されません）。

  孤立ファイル
    タスク（タイトル・説明・コメント・チェックリスト）、Wiki、プロジェクト設定の
    どこからも参照されていないファイルを、プロジェクト別にサイズ付きで表示します。
    チェックを付けて「ゴミ箱へ移動」します（初期状態は全選択）。
    完全には削除されず、files/_trash/ に移されます。

  ゴミ箱
    移したファイルを選んで「元に戻す」か、「ゴミ箱を空にする」で完全に削除できます。
    元の場所に同名のファイルがあるときは、上書きせずに戻しません。

  リンク切れ参照
    本文に tfz:// のリンクがあるのに、ファイルが見つからないものを一覧にします。
    表示と参照元へのジャンプだけで、本文は書き換えません。

  使用中のファイル
    プロジェクト別に、ファイル名・サイズ・参照元を表示します。

  安全のため、移動の直前にもう一度スキャンし、他の人が保存した直後の参照も
  確認します。ディスク上のプロジェクトファイルを一部読み込めなかったときは、
  判定が不確実なので移動できません。
  ※ ZIP でのプロジェクトエクスポートは、この機能の対象外です。

20. よくある質問
================================================================================

Q. フォルダを開こうとすると「アクセスが拒否されました」と表示される
A. Chrome のセキュリティ制約により、前回のフォルダアクセス許可が
   セッション間で失われることがあります。
   「📂 別のフォルダを開く」から再選択してください。

Q. 複数人で同時に保存するとどうなりますか？
A. 保存のたびにファイルを読み直し、他の人の変更とマージします。
   別タスク・別プロジェクトへの変更は自動マージされます。
   同じ項目を変更していた場合は競合として扱われ、手動保存ではダイアログが
   表示されます。自動保存中の競合は「保留」され、画面下のバナーや Ctrl+S から
   後で解決できます（6章参照）。

Q. OneDrive / Dropbox の競合コピーファイルが発生した場合は？
A. 次回フォルダを開いたときに自動検出し、3-wayマージを実行します。
   競合のない変更は自動マージ、競合がある場合は手動解決ダイアログが表示されます。
   解決後、競合コピーファイルは自動的に削除されます。

Q. スマートフォンやタブレットで使えますか？
A. 使えます（v1.2.0〜）。フォルダを選べないブラウザでは自動で「スマホモード」で
   起動します。PC とは同期パッケージ（JSON）でデータを受け渡します（18章参照）。

Q. チャートにデータが表示されない
A. バーンダウンチャートはストーリーポイントが設定されたタスクが必要です。
   ガントチャートはタスク・マイルストーンに開始日と期限が必要です。

Q. Markdown プレビューやバーンダウンチャートが表示されない
A. インターネット未接続環境では marked.min.js / chart.min.js が必要です。
   3章「フォルダ構成」の手順で、taskflowzero.html と同じフォルダに
   ファイルを配置してください。
   ※ シンタックスハイライト（highlight.js）とフォント（Google Fonts）は
     CDN取得失敗時も自動フォールバックするため、手動配置は不要です。

Q. 使われていない添付ファイルを整理したい
A. 「⚙️ 設定 → 📎 添付ファイル」でスキャンし、孤立ファイルを「ゴミ箱」へ
   移せます（19章参照）。

Q. マイタスクのメンションが「未読」のまま減らない
A. カードをクリックしてタスクを開くと既読になります。「すべて既読にする」で
   まとめて既読にもできます。名前が未設定だと判定できないため、右上の
   アカウントで名前を選択してください（13章参照）。

Q. Markdown に書いた HTML や画像が表示されない
A. v1.2.3 以降は、安全のため HTML をサニタイズして表示します。<iframe> や
   <svg>、id 属性などは取り除かれ、外部の画像は https のものだけ表示されます
   （12章参照）。http の画像は、添付ファイルにしてください。

Q. 添付ファイルが表示されない
A. ファイルはデータフォルダ内の files/P{n}/ に保存されます。
   データフォルダを別PCや別の場所で開く場合は、files/ フォルダも一緒に
   コピーしてください。

Q. @メンションの候補が表示されない
A. プロジェクトにメンバーが設定されていない場合、候補は表示されません。
   プロジェクト設定（✏️ ボタン）からメンバーを追加してください。

Q. プロジェクトを他の環境（別のデータフォルダ）に移したい
A. プロジェクト設定の「保存」タブからエクスポートし、移行先の
   「プロジェクト一覧」画面から「📥 インポート」でインポートしてください
   （8章参照）。添付ファイルも移行したい場合は、エクスポート時に
   「添付ファイルを含める」にチェックを入れて .zip 形式でダウンロードして
   ください。.json 形式のみの場合、添付ファイルの実体は含まれません。

Q. Wikiの見出しへのリンクをコメントに貼ったのに、クリックしても
   見出しにジャンプしません
A. リンク先の見出しの文言が変更・削除された可能性があります。
   見出しへのリンクは見出しの文言から自動生成されたIDに基づいているため、
   文言を変更すると既存のリンクは無効になります（11-5章参照）。
   お手数ですが、見出し横の🔗アイコンから新しいリンクを貼り直してください。
   ページ自体へのリンク（見出し指定なし）は引き続き有効です。
