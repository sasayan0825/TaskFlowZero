// コア機能

クラウドなし。インストールなし。
それでもフル機能。

🔒
データが外に出ない
ローカルまたは社内共有フォルダに保存。クラウドへの通信は一切なし。セキュリティポリシーが厳しい環境でも安心。
📦
インストール不要
taskflowzero.html をダブルクリック。それだけで動きます。IT管理者への申請も、セットアップも不要。
👥
チームで共有
共有フォルダを選択するだけ。3-way マージで同時編集の競合を自動解決。別プロジェクトは同時編集しても競合なし。
📶
完全オフライン対応
CDN が使えない環境でも動作。marked.min.js と chart.min.js をフォルダに置けば完全オフラインで全機能が使えます。

  • スプリント別グラフ

// 使い方

5分でセットアップ完了。

01
ダウンロード

taskflowzero.html を1ファイルだけダウンロード。ZIP展開も不要。

taskflowzero.html  ← これだけでOK
02
ブラウザで開く

Chrome または Edge でファイルをダブルクリック。フォルダを選択して「✨ 新規作成」。

任意のフォルダ/
  ├── taskflowzero.html
  └── project_P1.json  ← 自動生成
03
チームと共有（任意）

共有フォルダ（OneDrive・NAS 等）を選択するだけで全員が同じデータを参照・編集。

共有フォルダ/
  ├── project_P1.json
  ├── project_P2.json
  └── files/  ← 添付ファイル
